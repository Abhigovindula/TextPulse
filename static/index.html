    Powered by deep learning

    Four recurrent architectures were trained and evaluated under the same conditions for six-class emotion classification.

    RNN

    Baseline

    Reads text one token at a time and carries a hidden state forward. The simplest recurrent design.

    LSTM

    Gated memory

    Adds gates and a memory cell so relevant context can survive across longer sentences.

    GRU

    Lighter gating

    Uses a simpler gating scheme than LSTM, with fewer parameters to train.

    Serving this app

    Bi-GRU

    Two-way context

    Runs a GRU forwards and backwards, so each word is read with what comes before and after it.

    About TextPulse

    TextPulse is an NLP-based emotion classification system built with TensorFlow/Keras. It processes natural language using tokenization, sequence padding, embeddings, and deep-learning architectures to classify text into six emotion categories.

    • Sadness
    • Joy
    • Love
    • Anger
    • Fear
    • Surprise

    What happens to your text

    1. Clean Lowercase, remove apostrophes and punctuation.

      InputI can't believe it!!

      Cleanedi cant believe it

    2. TokenizeWords become integer IDs using the tokenizer saved from training.
    3. Pad to 50Every input becomes a fixed sequence of 50 tokens.
    4. Embed and classifyThe Bi-GRU model reads the sequence in both directions.
    5. Six probabilitiesOne score per emotion. The highest wins.
